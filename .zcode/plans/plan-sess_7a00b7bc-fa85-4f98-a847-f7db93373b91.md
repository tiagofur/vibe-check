# Fix pack — exportar el reporte como prompts de corrección

Sí es posible y encaja perfecto: cada hallazgo ya trae `file`, `lines`, `explicación` y `fix` sugerido. La idea: convertirlos en **prompts listos para pegar en tu agente IA** (Cursor, Claude Code, Copilot) y corregir hallazgo por hallazgo.

## 1. `src/lib/fix-prompts.ts` (puro, testeado — mismo patrón que roast.ts)

- **`buildFindingPrompt(finding)`**: prompt autocontenido para UN hallazgo:
  ```
  Arregla este hallazgo de auditoría VibeCheck en `src/auth/login.ts` (líneas 3).

  [CRÍTICO · seguridad] Stripe live key
  Problema: se detectó una clave live de Stripe hardcodeada...
  Corrección sugerida: revoca la credencial, muévela a variables de entorno...

  Limita el cambio a este hallazgo: no refactorices de más ni toques código
  ajeno. Al terminar, verifica que los tests pasan y que el hallazgo
  desaparece re-auditando con VibeCheck.
  ```
- **`buildFixPack(report)`**: documento markdown descargable con:
  - Encabezado: repo, score, veredicto, motor (IA/determinista), fecha, y el desglose "¿por qué el score?" (reutiliza `scoreExplanation`)
  - **Checklist índice**: `- [ ] 1. [CRÍTICO] título — archivo` para tachar a medida que corrige
  - Una sección por hallazgo (ordenado: crítico→bajo, verificados por scan primero) con el prompt dentro de un bloque de código, listo para copiar
  - Footer: cómo re-auditar (CLI + badge)

## 2. UI (`repo-report-view.tsx`)

- Botón **"🛠 Fix pack"** junto a "Copiar reporte MD": descarga `vibecheck-fixes-<repo>.md` (Blob + download) y copia al portapapeles con toast.
- En cada hallazgo del acordeón: botón chico **"Copiar prompt"** que copia solo el prompt de ese hallazgo — para corregir uno por uno sin descargar nada.

## 3. CLI: `--fix-pack`

`bun cli.ts tests/fixtures/vibe-coded-repo --fix-pack > fixes.md` — imprime el pack a stdout (útil también para agents automáticos).

## 4. Tests + docs

- `tests/fix-prompts.test.ts`: orden por severidad, checklist sincronizada con secciones, prompt contiene archivo/líneas/fix, caso sin hallazgos ("Nada que corregir 🎉").
- READMEs (es+en): una línea en modos/features.
